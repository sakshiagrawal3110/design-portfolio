Design System — TL;DR

  • The Problem: UI patterns evolved around one-off pages without shared rules, creating duplicate variants and inconsistent experiences across markets.
  • The Shift: Rebuilt foundations first (activation blue #165EDA, modular type, 12/24/36/48 spacing) and framed buttons around Intent, Variant, and State.
  • Governance: Embedded accessibility early and ran recurring UX Open Houses so the 51st screen is easier to build well.

Buttons

Primary button (Filled)

Purpose

  • Use for the main action on a page or module.
  • Should be the most visually prominent CTA.
  • Only 1 primary CTA per screen is recommended.

✓ Use cases

  • Hero banners
  • Submitting a form
  • Any action the user should immediately take

✕ Do not use

  • Less important tasks
  • Multiple times in a page
